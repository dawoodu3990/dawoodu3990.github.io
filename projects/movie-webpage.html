Zombie Project

Context

This project is about surviving a zombie apocalypse. It was created using HTML and CSS as a group project. Through this project, I learned how to work with others, share ideas, and build a website as a team.

Content

To explain in more detail, this project was about living and surviving during a zombie apocalypse. It explores what life would be like if you were in a world filled with zombies. I think this was a cool project because almost everyone has watched or heard about some type of zombie movie. This project allowed us to put ourselves in someone else's shoes and imagine what our lives would be like in a zombie apocalypse.

Challenges

One of the challenges I faced while coding was fonts. Adding the fonts to the code was not the problem. I forgot the link that I had to copy. There were many links, so I had to go back to the fonts lesson and look at all the slides again. After that, it was pretty easy, as I knew which links to copy and use.

Takeaways

A takeaway from this challenge is that you should be careful about which links you choose while making a webpage because you should choose ones that fit your theme and work best with your topic. Otherwise, you might ruin the reader's vibe because you picked a font that does not fit the theme.

Next Steps

My next step would be to implement JavaScript to make the website more interactive. I would also like to create more pages and add additional features to turn it into a fully functional website.
